# De Tekstploeg

Vier onafhankelijke redacteurs voor verschillende vragen over een Nederlandse tekst.

## De Structuurlezer

Gebruik deze skill wanneer de inhoud er staat, maar hoofdlijn, volgorde of redenering nog niet overtuigt. De skill signaleert concrete structuurproblemen en herschrijft niets automatisch.

```text
Gebruik $de-structuurlezer. Controleer de hoofdlijn en volgorde van dit artikel.
Herschrijf nog niets.
```

## De Factchecker

Gebruik deze skill wanneer namen, cijfers, citaten, causaliteit of actuele claims moeten worden gecontroleerd. De skill zoekt passende bronnen, scheidt feiten van interpretaties en maakt bewijsgrenzen zichtbaar.

```text
Gebruik $de-factchecker. Controleer de maximaal tien belangrijkste claims in
deze tekst tegen actuele bronnen. Laat de tekst zelf ongewijzigd.
```

## De Tegenlezer

Gebruik deze skill vóór publicatie of besluitvorming. De skill zoekt concrete risico's op misverstanden, irritatie en ongeloofwaardige claims vanuit vier lezerslenzen.

```text
Gebruik $de-tegenlezer. Lees dit voorstel tegen vanuit vier lezerslenzen.
Herschrijf nog niets.
```

## De Cliché-verwijderaar

Gebruik deze skill wanneer inhoud, feiten en structuur grotendeels kloppen, maar de taal voorspelbaar, opgeblazen of algemeen klinkt. De skill herschrijft en bewaakt de stem.

```text
Gebruik $de-cliche-verwijderaar. Bewerk deze tekst grondig.
Behoud alle feiten, citaten en mijn directe toon.
```

## Samen gebruiken

Voor een volledige redactieronde is dit de logischste volgorde:

1. **Structuurlezer** — klopt de route van de tekst?
2. **Factchecker** — worden de dragende claims door bronnen gedragen?
3. **Tegenlezer** — waar kan de lezer afhaken of je niet geloven?
4. **Cliché-verwijderaar** — kan de formulering scherper en oorspronkelijker?

Gebruik niet automatisch alle vier. Een korte tekst met een heldere lijn en weinig controleerbare claims heeft soms alleen taalredactie nodig. Bij een feitelijk gevoelig artikel kan De Factchecker juist de belangrijkste eerste stap zijn.
